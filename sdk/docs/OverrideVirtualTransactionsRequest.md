# com.finbourne.lusid.model.OverrideVirtualTransactionsRequest
Upserts overrides and suppressions of virtual transactions generated by a single instrument event.  Overrides are keyed by the virtual transaction id being overridden; suppressions are the list of virtual  transaction ids being suppressed. A virtual transaction id must not appear in both. This is a full  replace of the previously stored overrides and suppressions for the targeted instrument event - any  previously stored entry not present in this request is removed.

**suppressions** | **List&lt;String&gt;** | The virtual transaction ids to suppress. A virtual transaction id cannot also appear in Overrides. | [optional] [default to List<String>]
